Setup Credentials

To use Tune2Tube, you need to set up credentials for both Spotify and Google (YouTube).

Spotify Credentials

  1. Go to the Spotify Developer Dashboard.
  2. Create an app to get a Client ID and Client Secret.
  3. Create a `.env` file in the root of this project.
  4. Add the following lines to the `.env` file:
CLIENT_ID=your_spotify_client_id
CLIENT_SECRET=your_spotify_client_secret

Google Credentials

  1. Go to the Google API Console.
  2. Create a new project.
  3. Enable the YouTube Data API v3.
  4. Create credentials for a "Desktop app".
  5. Download the JSON file and rename it to `client_secret.json` in the root of this project.
